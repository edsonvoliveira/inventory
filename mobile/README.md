# Mobile mockup (Flet) — Offline + SQLite + Barcode Scanner

## O que contém
- UI mockup completo (T1..T6)
- Banco SQLite local com as tabelas definidas por você:
  - local_user_profile
  - local_locations
  - local_events
  - local_zones
  - local_products
  - local_barcodes
  - local_inventory_items
- Scanner por câmera usando OpenCV + pyzbar (desktop)
- Tema dark por padrão + toggle light
